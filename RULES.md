# Project Rules — Hyperliquid Trading Bot

## Rule #1: Commit, Commit, Commit
Every time you make a change to your project, commit (save) to GitHub. This is your checkpoint and the most important rule for maintaining project integrity and tracking progress.

## Rule #2: Take Time to Understand How It All Fits Together
Before making changes or adding features, take the time to understand how the code, modules, and trading logic connect. This avoids mistakes and ensures smooth development.

## Rule #3: Always Run Your Checks Before Committing and Deploying
Test and validate your changes before committing and deploying. Always run your checks to ensure trading logic, risk controls, and integrations work as intended.

## Rule #4: Break Tasks Into Small Steps
Divide work into small, manageable tasks. This makes it easier to commit frequently, test changes, and maintain high code quality.

## Rule #5: Do not create USELESS markdown documentation
Do not create comprehensive summary or final visual summary. All markdown documentation generated by the agent MUST be in the docs/ folder
---

*Following these rules helps keep your trading bot reliable, maintainable, and safe for live trading.*
